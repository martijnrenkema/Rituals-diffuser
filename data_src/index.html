Manual upload

FirmwareChoose or drop a firmware_*.bin file
Web interfaceChoose or drop a littlefs_/spiffs_*.bin file
Upload the firmware first, then the web interface. The diffuser restarts after each file. The ESP8266 switches to Safe Update mode for uploads; you will be redirected to a simple upload page.

Safe Update mode

The ESP8266 needs a dedicated update mode. MQTT pauses and you will be redirected to the upload page.
